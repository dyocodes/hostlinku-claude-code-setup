# Changelog

## 0.1.0 - 2026-11-18

- Initial release.
- Ready-to-use `settings.json` templates for Economy and Performance Service Modes (`configs/`).
- VS Code extension environment template (`configs/vscode-settings.json`).
- Shell export helper (`scripts/export-env.sh`) and dependency-free Node.js connection verifier (`scripts/verify-claude-code.mjs`) testing both `POST /v1/messages/count_tokens` and `POST /v1/messages`.
- Multilingual README (`en`, `id`, `ja`, `zh-CN`) and CI validation workflow.
